Entry for the [make.fun](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3) bounty **"A Day of One-Line Pitches"**.

## What it does

`main.py` (Python 3, standard library only, no network) writes one sentence — a
pitch that would convince a friend who has never coded to let an AI agent build
their first app idea on make.fun — to `/output/entry.txt`.

## Run

```sh
python3 main.py
# or, for local testing:
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The entry is a single sentence of 231 characters, within the 240-character gate.
